只想用其中一个？下面勾选时只选那一个就行，不需要全部安装。

第 1 步

准备好 API Key

还没有账号或 Key？先按手册首页完成注册登录、确认额度和创建 API Key，再回到这里。

不同软件需要的 Key
要用的软件创建 Key 时选的厂商
Claude CodeAnthropic（Claude 模型）
CodexOpenAI（GPT 模型）
WorkBuddy两种都可以

不确定也没关系：第 3 步会自动检查 Key 能用哪些模型，不匹配会直接提示你。

第 2 步

一键安装软件

已经装好的软件可以不勾。脚本只从国内能访问的官方渠道和镜像下载，已经装过的会自动跳过。

勾选要安装的软件

安装脚本里没有任何 Key，可以放心保存，以后重装还能再用。

下载以后怎么做

  1. 1

    保留下载的文件

    浏览器可能提示“此类文件可能会损害你的设备”。这是浏览器对所有脚本文件的通用提醒，点击“保留”即可。

  2. 2

    双击运行 huima-install.cmd

    打开浏览器的“下载”列表，双击 huima-install.cmd。如果出现蓝色窗口“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。

  3. 3

    需要授权时点“是”

    安装 Node.js 时 Windows 会弹出授权窗口，点击“是”。其他时候不用操作，看着窗口里的进度等待即可，通常几分钟到半小时。

  4. 4

    看到“安装结果”就完成了

    每个软件后面显示“完成”就说明装好了。显示“失败”时，检查网络后重新双击脚本，已装好的会自动跳过。按任意键关闭窗口，继续第 3 步。

脚本具体会做什么？
每个软件的安装来源
软件怎么安装
Claude Code先检查 Node.js，没有就从 npmmirror 国内镜像下载官方安装包并校验；再从国内镜像安装 @anthropic-ai/claude-code。
Codex 桌面版用 Windows 自带的 winget 从微软商店安装（商店编号 9PLM9XGG6VKS）。失败时打开商店页面，并从国内镜像安装 Codex 命令行版，配置方法相同。
WorkBuddy用 winget 安装腾讯官方安装包 Tencent.WorkBuddy。失败时打开 WorkBuddy 官网，由你点击下载安装。

脚本不会关闭杀毒软件，不会修改系统安全设置，也不会读取你的文件。安装日志保存在 %LOCALAPPDATA%\HuimaSetup\logs，出问题时可以发给客服。

WorkBuddy 装好后需要用它自己的账号登录（按软件提示操作），这和汇码账号是分开的。

第 3 步

一键配置：把 Key 填进软件

在下面粘贴 Key、选好模型，下载配置脚本并双击运行，软件就会连上汇码。

1. 勾选要配置的软件

勾选的软件都会用这把 Key。某个软件要用另一把 Key，在下方它的卡片里展开“用另一把 Key”填写。

3. 确认每个软件的模型

Claude Code

高级：按角色指定模型（已自动选好，一般不用改）

Claude Code 会按任务调用不同角色的模型。分组里没有的角色，会自动用最接近的可用模型代替，避免调用不存在的模型而报错。

用另一把 Key

填写后点上方“读取可用模型”。

Codex

用另一把 Key

填写后点上方“读取可用模型”。

WorkBuddy

用另一把 Key

填写后点上方“读取可用模型”。

粘贴 Key 后，点击“读取可用模型”。

点“读取可用模型”时，页面会用你的 Key 向汇码查询模型列表，这一步不产生费用。Key 不会被保存，离开页面自动清空。

下载以后怎么做

  1. 1

    先关掉要配置的软件

    关闭 Claude Code 的命令窗口、Codex 和 WorkBuddy，避免它们覆盖新配置。

  2. 2

    双击 huima-config.cmd

    和安装脚本一样，提示时选“保留”“更多信息 → 仍要运行”。窗口里会列出要配置的软件，确认后输入 Y 并回车。

  3. 3

    看到“配置完成”

    每个软件后面显示“完成”就好了。最后会问是否删除这个脚本：输入 Y 回车，关闭窗口时它会自动删除，Key 不会留在下载文件夹里。

配置脚本会改哪些文件？
写入位置（%USERPROFILE% 是你的用户文件夹）
软件写入的文件和内容
Claude Code.claude\settings.json：汇码地址、Key、主模型，以及 Fable / Opus / Sonnet / Haiku / 子代理各角色对应的模型；.claude.json：标记已完成首次引导，打开时不再要求登录 Anthropic 账号。其他设置保持不变。
Codex.codex\config.toml：添加“汇码”服务商并设为默认；.codex\auth.json：保存 Key（原来的登录信息会先备份）。
WorkBuddy.workbuddy\models.json：添加汇码自定义模型，保留你已有的其他自定义模型。

修改前，原文件会备份到 %USERPROFILE%\.huima\backups。随时可以用恢复脚本还原。备份里可能有你以前的 Key，不要发给别人。

第 4 步

发一条消息，确认已经接通

每个软件发一条短消息测试，再去汇码使用记录看到对应的记录，就说明全部完成了。测试消息也会产生少量费用，发一次就够。

请只回复四个字：连接成功。

Claude Code

  1. 1

    建一个练习文件夹

    在桌面新建文件夹，例如“AI练习”，不要放重要文件。Claude Code 能读写这个文件夹里的内容。

  2. 2

    在文件夹里打开命令窗口

    打开“AI练习”文件夹，点击窗口顶部的地址栏，输入 powershell 并回车，会弹出一个命令窗口。

  3. 3

    输入 claude 并回车

    第一次会问是否信任这个文件夹，确认是练习文件夹后选择信任（Yes）。然后粘贴测试消息并回车。

Codex 桌面版

在开始菜单搜索“Codex”打开，选择练习文件夹，新建对话，粘贴测试消息发送。如果安装时改装成了命令行版，按上面 Claude Code 的方法打开命令窗口，输入 codex 回车即可。

如果 Codex 桌面版打开后仍要求登录 ChatGPT 账号，先关掉它，改用命令窗口里的 codex，并告诉客服你的 Codex 版本。这种情况不要为了登录去购买 ChatGPT 订阅。

WorkBuddy

打开 WorkBuddy 并登录。在聊天输入框附近的模型下拉框里，选择刚才配置的模型（不要选“Auto”），粘贴测试消息发送。

在模型列表里没找到汇码的模型？先完全退出 WorkBuddy 再打开。还是没有的话，按进阶路线的 WorkBuddy 步骤在设置里手动添加，只需填三项。
完成标志：软件正常回复，并且汇码使用记录里能找到这条请求。没有回复或报错时，查看常见问题。

以后会用到

换 Key 或换模型

回到第 3 步，粘贴新的 Key 或选择新模型，重新下载配置脚本并运行即可。新配置会覆盖旧配置，覆盖前同样会自动备份。

只想换其中一个软件，第 3 步只勾选那一个。换下来的旧 Key 如果不再使用，记得到汇码 API 密钥页面禁用它。

以后会用到

恢复原来的配置

想撤销汇码的配置，回到运行配置脚本之前的样子，下载恢复脚本并双击运行。它会还原最近一次配置前的文件；再运行一次，可以继续还原更早的一次。

恢复脚本里没有 Key，可以放心保存。

恢复只影响本机软件的设置，不会删除汇码账号里的 Key。要彻底停用某把 Key，请到汇码 API 密钥页面禁用。

遇到问题

常见问题

按出现的现象查找
看到什么怎么处理
浏览器说文件可能有害在下载列表点“保留”。脚本来自本手册页面，内容可以用记事本打开查看。
“Windows 已保护你的电脑”点击“更多信息”，再点“仍要运行”。
窗口一闪就没了确认下载的是 .cmd 文件，而不是 .txt。请直接双击运行，不要选“以管理员身份运行”，否则配置可能写到别的账户里。仍然闪退时联系客服。
杀毒软件拦截选择“允许”或“信任”这个文件，不需要关闭杀毒软件。拿不准时把截图发给客服。
提示没有 wingetWindows 10 较老的版本可能没有。在微软商店搜索“应用安装程序”并更新，再重新运行安装脚本。Claude Code 不受影响。
Codex 桌面版装不上脚本会自动改装命令行版，可以正常使用。想要桌面版，可在打开的微软商店页面点“获取”。
“claude 不是内部或外部命令”关闭所有命令窗口，重新打开再试。仍然不行就重新运行安装脚本，查看“安装结果”。
Claude Code 仍要求登录确认已运行配置脚本并显示“完成”，然后关闭命令窗口重新打开。还不行把配置脚本窗口的截图发给客服（先遮住 Key）。
401 / Key 无效Key 可能复制不完整或已被禁用。到汇码重新复制，回到第 3 步重新生成配置脚本。
403 / 模型不存在Key 的分组不支持这个模型。回到第 3 步点“读取可用模型”，从列表里重新选。
余额不足 / 429查看账户余额和 Key 的额度限制，暂停反复重试。详见手册首页的排查表。

还没解决？按求助模板联系客服，附上脚本窗口截图或日志文件夹。截图前遮住 Key。
