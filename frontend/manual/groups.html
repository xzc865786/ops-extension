第 3 步 · 创建 Key 前看一看

选对分组，再创建 Key。

创建 API Key 时要选一个分组。分组决定这把 Key 能用哪些模型、适合哪个软件，以及按什么倍率扣费。先确定要用的软件，再从下面挑一个合适的分组。

  1. 1

    先确定要用的软件

    Claude Code 用 Anthropic 风格的 Key；Codex 和 WorkBuddy 用 OpenAI 风格的 Key。

  2. 2

    找到适用这个软件的分组

    在下方分组一览点软件名筛选，对比倍率、适用场景和主要模型。

  3. 3

    创建 Key 时选同名分组

    在网站API 密钥页创建密钥，“厂商”选对应风格，“分组”选和这里同名的分组。

选好以后

按分组创建 Key

回到手册首页的创建 API Key，在弹窗里先选“厂商”（Key 的风格），再从“分组”下拉框选好分组，其余步骤不变。

同时要用几个分组？一把 Key 只属于一个分组，要用几个分组就分别创建几把 Key，给每把起个好认的名称，例如“Claude 日常”“Codex 实惠”。

软件报 403 或“模型不存在”，多半是 Key 的分组不支持当前模型：在一键配置或 CC Switch 页面点“读取可用模型”，从列表里重新选；仍不行就换一个适用的分组重新创建 Key。

遇到问题

分组常见问题

倍率是什么意思？

倍率是在模型基础价格上乘的系数：倍率越低，同样的用量扣费越少。实际扣费还和所用模型、输入输出的 Token 数量有关，倍率不能直接换算成人民币价格。

一把 Key 能同时用几个分组？

一把 Key 只属于一个分组。要用不同分组的模型，就分别创建几把 Key。

选错了分组怎么办？

重新创建一把 Key，选对分组，再把新 Key 填进软件。旧 Key 不用了，在密钥列表里禁用即可。

为什么下拉框里没有某个分组？

创建 Key 时先选的“厂商”（Key 的风格）会筛掉其他风格的分组；部分分组是专属分组，需要开通后才能看到。不确定时联系客服。

还是拿不准？按求助模板告诉客服要用的软件和大致用量，客服会帮你推荐分组。
