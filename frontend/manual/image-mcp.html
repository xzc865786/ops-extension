02 · 安装与连接
跟着助手，一步步连接
安装包包含配套运行环境，无需打开终端，也不用手动修改配置文件。当前下载入口提供 Windows x64 安装包，适用于 Windows 10 1809 或更新的 64 位 Windows。

        
    
          
  1. 1
    下载并双击安装助手
    在本页顶部下载完整安装包，双击打开“汇码生图安装助手”。欢迎页显示“把想法变成图片”，点击“开始设置”。
    系统提示来源或安全检查时，先核对下载渠道和文件信息。不要关闭系统防护；无法确认时联系客服。
    2. 
          
  2. 2
    选择你平时使用的软件
    可以选择多个。助手会标记是否发现用户配置；已经安装但未检测到时，可以打开过一次软件后“重新检测”，也可手动勾选。
    保存正在进行的工作，并完全退出所选软件。助手不会强制结束你的聊天。
    3. 
          
  3. 3
    粘贴生图 Key，验证并继续
    Key 只填进本机安装助手。点击“验证并继续”，助手只查询模型列表，不会生成图片。本机已有 Key 时，留空可继续使用。
    提示 Key 无效时，请重新复制完整 Key；提示没有生图模型时，请检查分组权限。
    4. 
          
  4. 4
    选择图片保存位置
    默认放在“图片 / 汇码生图”。可以点击“更改位置”，选择可写的本地文件夹。助手会创建目录并检查写入权限。
    5. 
          
  5. 5
    确认设置，安装并连接
    核对软件、Key 使用方式和图片目录，确认已退出客户端，再点击“安装并连接”。助手校验程序文件、写入本工具配置，并检查 MCP 工具能否启动和被发现。
    发现已有其他“汇码生图”配置时，默认保留；只有你明确选择替换，才会覆盖此工具的条目。其他设置保留。
    6. 
          
  6. 6
    查看结果，重新打开聊天软件
    每个软件分别显示连接结果。某个软件失败时，可以先使用成功的软件，再单独处理失败项。
    “工具连接检查通过”表示本机工具可以启动并列出功能；第一张图片需要你主动发送指令。
    7. 
        

        
安装与连接检查不生成图片。发送生图或改图指令后，才会调用相应服务并产生费用。

      

      

        
03 · 生成第一张图
把汇码的理念，画成一张图
先选你使用的软件，再复制下面的指令。

        

        
完全退出并重新打开 WorkBuddy。进入“专家·技能·连接器” → “连接器” → “自定义连接器”，在 MCP 服务管理中检查 huima-image。按提示信任后，确认连接正常、3/3 工具启用，再新建聊天并发送指令。

        
发送指令后会调用生图服务并产生费用。出现工具授权提示时，请核对是“汇码生图”及本次需要执行的操作，再决定是否允许。

        
示例：汇码品牌理念插画
Flare · low
请使用汇码生图工具，调用 Flare 模型，以 low 质量生成一张“汇码智能”的品牌理念插画。汇码智能提供 AI API、软件服务与定制开发。画面以一个智能青色的核心连接多个石墨色模块，模块逐步构成应用界面、代码窗口和创作画布，表达技术能力汇聚、连接并转化为实际应用的过程。采用简洁的几何插画风格，以石墨色和智能青为主，白色或浅灰背景，构图有秩序、留白充足，体现专业、现代、克制的科技感。不要添加文字，不要绘制或改造官方 Logo，不使用霓虹、发光或金属效果。完成后展示预览，并告诉我原图保存位置。

        
成功后，助手会返回图片预览和原图保存位置。聊天界面没有显示图片时，可以打开 HTML 预览或原图文件。

        
此示例不指定尺寸。图片的实际像素以生成结果为准；以后如果明确请求了尺寸，却收到不同像素的图片，属于接口返回异常。保留原图和请求记录，不要反复重发。

      

      

        
04 · 日常创作
有了第一张图，还可以这样用

        
继续修改上一张
在同一聊天里说明要保留什么、改变什么，让助手读取上一张原图继续修改。

        
请使用汇码改图工具，把上一张图片调整为深色背景，保留智能青核心和原有构图，提升模块与背景的对比度，并另存为新图片。

        
修改电脑里的图片
在文件资源管理器里选中图片，使用“复制文件地址”或“复制为路径”，把完整路径替换到下面的指令中。

        
请使用汇码改图工具，读取“这里替换为图片的完整路径”，保留画面主体，把背景改为简洁的浅灰色，并保存为新图片。

        
仅把图片拖进聊天框，不一定能让工具读取本地原图。请提供工具可访问的完整文件路径。参考图支持 PNG、JPEG、WebP，单张不超过 10 MiB。

        
怎么选模型和质量？
可以在指令中指定 Flare 或 Sunburst，质量可选 low、medium、high。聊天模型和生图模型分别选择；切换质量不会自动替换生图模型。实际费用以平台使用记录为准。

      

      

        
05 · 保存与分享
分享作品时，记得使用原图
聊天里的预览方便查看，原图保存在你安装时选择的文件夹中。每次生成或修改都有独立的结果目录。

        
原图用于分享、交付和继续编辑。
JPEG 预览缩小后的图片，适合快速查看。
HTML 预览在浏览器查看预览、实际像素和原图入口。

        
找不到图片时，可以问助手“上一张原图保存在哪里？”，或重新打开安装助手，点击“打开图片文件夹”。

      

      

        
06 · 以后会用到
更换配置，或者卸载工具
在开始菜单打开“汇码生图安装助手”，进入“管理已安装的生图工具”。也可以重新打开原安装包。

        
  • 检查连接：检查工具启动与发现，不生成图片。
  • 更换 Key 或保存目录：重新配置，并勾选需要更新的客户端。留空 Key 可沿用已保存的 Key。
  • 接入其他软件：勾选新增的软件，完成配置后重新打开它。
  • 卸载：移除本助手管理的连接。没有剩余连接时删除当前版本运行文件；保留图片、Key 和安装助手。其他来源的配置与旧版本文件不会强制删除。

        
不再使用的 Key，可以在平台密钥页面禁用。卸载本机工具不会自动禁用平台 Key。

      

      

        
07 · 遇到问题
先看看这里

        
助手说连接通过，聊天里却不能生图？
完全退出软件后重新打开，新建聊天，明确要求“使用汇码生图工具”。仍不可用时，在安装助手里检查连接，并将脱敏诊断信息提供给客服。

        
一直在等，或者提示超时怎么办？
先查看图片保存目录和平台使用记录。Codex 中停止聊天不一定取消生图请求，也不代表不会计费。没有显示进度时，不能据此认定请求已经停止；不要连续重复发送。

        
提示 Key 无效、没有权限或没有生图模型？
检查 Key 是否完整、有效，以及是否属于开放生图权限的分组。更换生图 Key 不需要改动聊天软件的 Key。网络连接失败时，先检查网络和服务地址。

        
图片尺寸和我请求的不一样？
当前接口可能返回与明确请求尺寸不一致的图片，这是接口返回异常。请以实际图片像素为准，保留原图、请求尺寸及请求记录联系支持。工具不会自动重复生成，也不会偷偷缩放原图。

        
安装提示校验失败、文件占用或目录不可写？
校验失败时重新下载完整安装包，不要跳过校验。文件占用时先保存工作并退出相关软件；目录不可写时改用自己的“图片”或“文档”目录。需要帮助时复制助手提供的诊断信息。

        
为什么有的软件成功，有的软件失败？
每个客户端配置单独处理。已有其他同名配置、配置格式异常或文件正在被修改时，相应客户端会单独显示失败。可以先使用成功的软件，再重新配置失败的软件。
