# 在干净虚拟机里测试使用手册

你的 VPN（sing-box）是系统代理模式，虚拟机上网不经过它，天然就是国内直连，**不用关 VPN**。

## 已经准备好的

| 东西 | 位置 / 说明 |
| --- | --- |
| 手册测试服务 | 已在本机运行，端口 18089。提供 `frontend/manual` 的最新内容，并把“读取可用模型”转发到 api.tysy.top |
| 创建虚拟机脚本 | `output\vm-test\create-vm.ps1`（同时添加一条只对虚拟机网段放行 18089 端口的防火墙规则） |
| 清理脚本 | `output\vm-test\remove-vm.ps1`（删除虚拟机、硬盘和这条防火墙规则） |

> 测试服务需要一直开着。如果本机重启或关掉了，在项目目录重新运行：`node output/vm-test/manual-server.mjs`

## 第 1 步：下载 Windows 11 镜像（你来做）

1. 微软会拒绝走代理的下载请求（报“我们在处理你的请求时遇到了问题”）。在 PowerShell 运行下面这条命令，打开一个不走代理的独立 Edge 窗口（单独的临时配置，不影响平时的 Edge，也不用关 VPN）：

   ```powershell
   Start-Process msedge -ArgumentList '--no-proxy-server', "--user-data-dir=$env:TEMP\edge-noproxy", 'https://www.microsoft.com/zh-cn/software-download/windows11'
   ```
2. 找到“下载 Windows 11 磁盘映像 (ISO)”，选择“Windows 11 (multi-edition ISO for x64 devices)”→ 确认。
3. 语言选“简体中文”→ 确认 → 点“64-bit 下载”。文件约 6 GB，存到比如 `D:\Downloads\`。

## 第 2 步：创建虚拟机（你来做，约 1 分钟）

1. 开始菜单搜索 PowerShell → 右键“以管理员身份运行”。
2. 执行（把 ISO 路径换成你实际的文件名）：

   ```powershell
   cd D:\work\huima\code\ops-extension\output\vm-test
   powershell -ExecutionPolicy Bypass -File create-vm.ps1 -IsoPath "D:\Downloads\Win11_25H2_Chinese_Simplified_x64.iso"
   ```

3. 弹出虚拟机窗口后，看到 **Press any key to boot from CD or DVD** 时，立刻点进窗口按任意键。错过了就点窗口菜单“操作 → 重置”再来。

虚拟机配置：4 核、内存 4–6 GB（动态）、硬盘 80 GB（按实际使用占空间），放在 `D:\HyperV\HuimaTest`。

## 第 3 步：安装 Windows 11（你来做，约 20–30 分钟）

> 本机内存紧张时，可以把虚拟机降到 3 GB：`Set-VMMemory -VMName HuimaTest -StartupBytes 3GB -MinimumBytes 2GB -MaximumBytes 4GB`。
> 这时安装程序会检查内存不足 4 GB：在第一个界面（选语言）按 `Shift + F10`，输入
> `reg add HKLM\SYSTEM\Setup\LabConfig /v BypassRAMCheck /t REG_DWORD /d 1 /f` 回车，关掉窗口后照常安装。
> 仍提示不满足要求时，在安装界面改用“以前版本的安装程序”，再执行一次这条命令。只影响虚拟机的安装程序。

1. 语言保持中文 → 现在安装 → “我没有产品密钥” → 选 **Windows 11 专业版** → 接受条款 → “自定义：仅安装 Windows” → 直接下一步。
2. 重启后进入设置向导，地区选中国，键盘默认。
3. **创建本地账户，不登录微软账号**（更像一台普通新电脑）：
   - 到“你想如何设置此设备”时选 **“设置用于工作或学校”** → **“登录选项”** → **“改为加入域”**，然后输入用户名（比如 `test`）和密码。
   - 如果没有这个选项：在登录页按 `Shift + F10` 打开命令窗口，输入 `start ms-cxh:localonly` 回车，按提示建本地账户。
   - 两个都不行就直接用微软账号登录，不影响测试。
4. 隐私选项全部关掉即可，进入桌面。
5. 系统没激活，右下角会有水印，不影响测试。

## 第 4 步：检查网络，拍“干净系统”快照（你来做）

在**虚拟机里**右键开始按钮 → “终端”，依次执行：

```powershell
curl.exe -I --max-time 10 https://www.google.com
curl.exe -I --max-time 10 https://registry.npmmirror.com
ipconfig | findstr 默认网关
```

应该看到：

- 第一条**连不上**（超时或报错）→ 说明是国内直连，测试结果可信。
- 第二条返回 `HTTP/1.1 200` 之类 → 国内网站正常。
- 第三条显示的“默认网关”地址（通常是 `172.28.0.1`）就是你本机，记下来。

然后在虚拟机的 Edge 里打开 `http://默认网关:18089/docs/`（例如 `http://172.28.0.1:18089/docs/`），能看到手册首页就说明一切就绪。

**拍快照**：关掉虚拟机（开始 → 电源 → 关机），在本机管理员 PowerShell 执行：

```powershell
Checkpoint-VM -Name HuimaTest -SnapshotName 干净系统
```

以后每次测完，用下面两条命令回到干净状态：

```powershell
Restore-VMCheckpoint -VMName HuimaTest -Name 干净系统 -Confirm:$false
Start-VM HuimaTest; vmconnect localhost HuimaTest
```

（也可以用开始菜单里的“Hyper-V 管理器”，右键检查点 → 应用。）
