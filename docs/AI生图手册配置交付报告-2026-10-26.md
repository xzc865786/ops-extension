- 后端增加 `image_mcp.downloads.windows_x64 / macos_arm64 / macos_x64`、`recommended_group_id` 和 `key_note`。各系统独立开关，提供文件库或地址来源、版本、适用系统、签名和补充提示。
- Windows 兼容值从原仓库发行清单提取：0.1.0、127,966,065 字节、`unsigned-preview`，SHA-256 为 `cebbe26b4286a0ade27284e5f17369c8254257214c914ede09ba4de3045bda66`。继续使用原静态 EXE，不要求重新上传。Mac 默认关闭，只保留结构。
- 推荐分组仅保存现有 `sub2api_id`，服务端从当前手册分组条目解析名称、厂商、摘要与说明。关联必须唯一且公开；隐藏、删除、取消关联或重复关联时阻止发布。公开生图配置不包含推荐关联 ID、分组内部 ID 或文件选择 ID。
- 上传文件名、大小、SHA-256 由服务端记录确定，保存时覆盖客户端同名字段；站内手册文件地址同样解析文件记录并保护引用。外部地址需完整发行元数据、合法地址和平台扩展名，保存过程不抓取外部地址。
- 后台新增“AI 生图”页签、推荐分组核对、下载与 Key 指引预览和共用文件库。复用保存发布、乐观版本检查、历史比较与恢复；新增字段有中文名称，旧版比较展开到字段。
- 在线生图页只读取后台公开配置，移除独立的 `image-mcp-release.json`。其他手册仍沿用原来的默认配置回退，生图下载在配置失败时保持禁用；新生图字段损坏不导致其他配置丢失。
- 下载按钮为“下载汇码生图安装包（Windows）”，展示用途、实际系统、版本、大小、签名及 SHA-256。暂停、元数据不完整或 HEAD 检查失败时移除下载地址并说明原因；无 Mac 包时，Mac 用户不会获得 EXE 下载入口。多个完整系统包就绪后才显示选择器。

## 兼容行为

旧配置、旧历史没有 `image_mcp` 时，读入和恢复均补入上述 Windows 静态包、关闭的 Mac 配置、无推荐分组。后台历史列表、比较及恢复确认说明使用兼容默认值；恢复旧版可能重新开放兼容 Windows 下载，操作前可在界面看到说明。

当前版本引用的生图文件（包括站内文件 URL）不可直接删除，即使下载暂停仍保留引用保护。解除引用后可删除；恢复引用已删除文件的历史版本返回明确的“文件不存在或已删除”错误。文件记录存在而实际存储不可用时，HEAD 返回 503，前台禁用下载，不回退到旧包。

离线 `file:` 阅读显示“随包手册”，不请求后台、不提供重复下载，保留维护提示。已发布的 0.1.0 安装包和其内置离线手册未重新打包，网站更新不会自动改变它们。
