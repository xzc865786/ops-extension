# 日期筛选统一与历史入口退役验证

2026-10-11 按用户确认的调整方案实施：支出记录和月度开支统一复用原双日历日期区间组件，桌面快捷项位于展开日历侧边，窄屏沿用原组件的单日历及换行快捷项。默认本月，可选本月、上月、本季度、上季度、本年、上年、近 12 个月及不限日期；自定义范围可跨月、跨年，起止日期均包含。付款人、分类、状态及关键词控件统一高度和对齐。

支出记录的待报销快捷入口清除日期限制，避免遗漏旧月份的新台账欠款；用户随后仍可选日期范围。列表、人民币汇总和完整 Excel 导出共享筛选逻辑，以支出日期筛选，报销日期不改变费用归属。

移除历史列表入口、核对提示、历史迁入表单、详情中的原单链接和 Excel 历史未核对提示；旧 `/admin/expenses/history` 书签跳回支出记录。数据库旧单据、付款、附件及事件保留，不自动迁入或重算。旧 API 和附件读取保留兼容，历史盘点／确认接口仍作为兼容接口保留，但新版不提供操作入口。

## 接口和数据库兼容

- 支出列表、`monthly` 和 `export` 新增可选 `date_from`、`date_to`（YYYY-MM-DD）；必须同时提供，顺序正确，跨度不超过 1096 天，与原日期选择器上限一致。完整日期区间优先于月份。
- 原 `month=YYYY-MM`、空月份表示不限日期、缺省月份默认本月的调用继续兼容。为旧调用保留 API 的 `unconfirmed_count` 字段，但新版不展示。
- 无数据库迁移、新依赖或环境变量变更。已保存金额和历史表数据不修改。Sub2API 嵌入菜单 URL 不变。
