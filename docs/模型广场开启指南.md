# 模型广场开启指南

模型广场是 Sub2API 自带的公开页面（`https://api.tysy.top/model-plaza`），**按分组展示可用模型和价格**。开启后，新首页导航中预留的「模型广场」入口即可使用。用户也能在这里查到准确的模型 ID，不必再问客服。

本指南基于线上 Sub2API **v0.2.8** 的实际代码编写。开启只需在后台拨一个开关，但页面展示什么，完全取决于分组、渠道和定价的配置，所以**请先完成「2. 开启前准备」，再打开开关**。

## 1. 先了解：页面上的内容从哪里来

```text
模型广场
 └─ 分组（只列出「状态正常」且至少有一个模型的分组；按倍率从低到高排列）
      ├─ 分组名称、描述、倍率、高峰倍率、是否专属
      └─ 模型列表 ← 来自「关联了该分组」且「状态正常」的渠道所支持的模型
            ├─ 实付价格 ← 渠道定价（没配时回落到全局价格表）× 分组倍率
            └─ 官方参考价 ← 全局价格表（查不到时不显示）
```

需要记住的四条规则：

| 规则 | 说明 |
| --- | --- |
| 模型来自渠道 | 模型广场不单独维护模型清单。一个模型要出现在某个分组下，必须有一个**状态正常**的渠道支持它，并且该渠道**关联了这个分组** |
| 平台要一致 | 普通分组只展示与分组平台相同的模型（例如 OpenAI 分组只展示 OpenAI 平台的模型） |
| 价格与扣费同源 | 展示价格和实际扣费使用同一套计算逻辑。页面上的价格就是用户实际支付的价格，配置错了会直接暴露 |
| 专属分组对访客隐藏 | 未登录访客只能看到**非专属**分组；登录用户还能看到自己被授权的专属分组，以及自己的专属倍率 |

## 2. 开启前准备

### 2.1 检查分组（分组管理）

逐个检查准备展示的分组：

- **名称和描述：** 访客直接看到这两项。名称要让人看懂，描述写清用途，例如「Claude 全系列，适合 Claude Code」。避免只有内部人员才懂的代号。
- **倍率：** 页面按倍率从低到高排序，并显示倍率和高峰时段倍率。确认数值是对外公开的价格。
- **专属分组：** 不希望公开展示的分组（内部测试、大客户专用、特价分组），务必设为**专属分组**，访客就看不到它。
- **状态：** 只有状态正常的分组才会展示。已停用的分组不会出现。

### 2.2 检查渠道（渠道管理）

- 每个要展示的模型，都要有一个**状态正常**的渠道，在「支持的模型」中包含它，并在「关联分组」中选上对应分组。
- **DeepSeek 和 GLM：** 新首页已写明「已接入」。它们的渠道上线并关联分组后，才会出现在模型广场。上线前访客在广场里看不到，这是正常的。
- 测试用、已废弃的渠道，要么停用，要么取消关联对外分组，否则其中的模型也会被展示出来。

### 2.3 检查定价（渠道管理 → 渠道定价）

- 为每个展示的模型确认价格。没有单独配置的模型，会使用全局价格表中的官方价。
- **DeepSeek、GLM 等模型，如果全局价格表里没有对应的模型名，价格一栏会是空的。** 这类模型务必在渠道定价中手动配置。
- 配置完成后，找一个低倍率分组，用测试密钥发一条短消息，核对「使用记录」中的扣费与广场显示的价格是否一致。

### 2.4 准备「价格说明」

模型广场顶部可以显示一段说明（支持 Markdown）。建议写清访客最常问的几件事，可参考：

```markdown
**计费说明**

- 按实际用量计费，价格单位为站内额度（$），**不等于人民币金额**。
- 实付价格 = 模型单价 × 分组倍率；标注了高峰倍率的分组，在高峰时段按高峰倍率计费。
- 充值与到账规则请在客服 QQ 群 1045113768 确认。
- 不同分组支持的客户端与协议不同，接入方法见 [使用手册](/docs/)。
```

金额单位、充值方式请以实际运营规则为准。

## 3. 开启步骤

1. 用管理员账号登录，进入 **系统设置 → 功能开关**，找到 **模型广场**。
2. 打开 **启用模型广场**。
3. **需要登录才可访问：建议关闭。**
   - 关闭时，访客不登录就能看到非专属分组的模型和价格，适合从首页引流。专属分组依然对访客隐藏。
   - 开启时，访客从首页点「模型广场」会被带到登录页。
   - 线上当前这个选项是**开启**的，请注意修改。
4. 在 **价格说明（Markdown）** 中粘贴 2.4 准备好的内容。
5. 保存设置。

开启后，Sub2API 自己的顶栏也会出现「模型广场」入口。

## 4. 验证

用**无痕窗口**（未登录状态）检查：

| 检查项 | 预期 |
| --- | --- |
| 打开 `https://api.tysy.top/model-plaza` | 显示「模型广场」页面、顶部的价格说明和分组列表 |
| 从新首页点导航「模型广场」 | 整个页面跳转到模型广场（开启前点击会回到首页） |
| 分组列表 | 只有准备公开的分组；**看不到专属分组** |
| 每个模型的价格 | 都有数值，与渠道定价一致；没有空白价格 |
| 页面提示 | 显示「登录后可查看你的专属分组与专属倍率」 |

再用一个**被授权了专属分组的测试账号**登录后访问，确认能看到该专属分组及其专属倍率。

命令行快速检查：

```bash
curl -sS -o /dev/null -w '%{http_code}\n' https://api.tysy.top/api/v1/model-plaza
# 开启前 404；开启且无需登录时 200；开启且需要登录时，未登录访问 401
curl -sS https://api.tysy.top/api/v1/model-plaza \
  | python3 -c 'import json,sys; d=json.load(sys.stdin)["data"]; [print(g["name"], "专属" if g["is_exclusive"] else "公开", len(g["models"]), "个模型") for g in d["groups"]]'
# 未登录时，列出的应全部是「公开」分组
```

## 5. 与首页、使用手册的衔接

- **新首页：** 导航已预留「模型广场」入口（`homepage-designs/03-holo-pop.html` 中的 `SITE.links.models`），开启后无需修改即可使用。
- **使用手册：** 建议在「03 创建密钥」和「04 连接软件」中「模型 ID 要填完整」的位置，加一句「可在 [模型广场](/model-plaza) 查看各分组的模型 ID 和价格」。这也解决了《使用手册优化建议》中的 C2。
- **首页「连接软件」：** 如需把模型一栏的提示改为「可在模型广场查看」，搜索页面中的 `const MODEL =` 修改即可。

## 6. 关闭或回滚

在 **系统设置 → 功能开关 → 模型广场** 关闭「启用模型广场」并保存，页面立即不可访问。关闭后：

- 访客从首页点「模型广场」会回到首页，已登录用户会进入控制台。不会报错，但入口看起来没有反应。
- 如果长期不开启，可在新首页中把 `SITE.links.models` 改为 `''`，隐藏入口。

## 7. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 页面显示「暂无可展示的分组」 | 没有任何分组同时满足：分组状态正常、有状态正常的渠道关联它、渠道支持的模型平台与分组平台一致。按 2.1、2.2 逐项检查 |
| 某个分组没有出现 | 分组已停用，或没有状态正常的渠道关联它；访客还看不到专属分组 |
| 某个模型没有出现 | 支持它的渠道已停用、未关联该分组，或模型平台与分组平台不一致 |
| 价格显示为空 | 渠道定价没有配置，全局价格表里也没有这个模型名（自定义名称或较新的模型常见）。在渠道定价中手动配置 |
| 访客被带到登录页 | 「需要登录才可访问」仍是开启状态，见第 3 节 |
| 开启后首页入口仍然回到首页 | 浏览器缓存了旧的站点设置。用无痕窗口或强制刷新（Ctrl+F5） |
