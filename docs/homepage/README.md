# 汇码智能首页 · v1 设计预览

本目录是独立首页设计稿，不参与运营扩展的构建，不会修改线上首页。

## 查看与维护

- `preview.html`：独立浏览器预览，登录和文档按钮指向生产域名；页内锚点留在预览。
- `sub2api-home.html`：可粘贴到 Sub2API「系统设置 → 站点设置 → 首页内容」的片段，使用 `/login` 与 `/docs/`。
- `home.css`、`home.template.html` 和 `assets/`：唯一维护源；请勿分别修改两个生成文件。
- 修改后运行 `python docs/homepage/build.py`，同步生成两个 HTML 文件。
- 本地预览可运行 `python -m http.server 4178 --bind 127.0.0.1 --directory docs/homepage`，打开 `http://127.0.0.1:4178/preview.html`。

素材来自 `huima_brand_identity_v1_final` 的官方 SVG 定稿，保留几何与颜色，仅为嵌入多个实例调整 SVG 内部 ID。页面为固定浅色，无脚本、外部字体或组件依赖；样式限定在 `#huima-home`。

## 本地验证

- Chromium 浏览器检查 1440、768、390、320 像素视口，无横向溢出。
- 页内「应用场景」「接入流程」锚点跳转正确；FAQ 可通过 Enter 展开与收起；跳过导航后焦点落在正文。
- 下载当前官网样式，在本地用 `innerHTML` 模拟 Sub2API 的 HTML 注入，检查宿主浅色与深色模式下的桌面及手机显示。首页保持浅色，宿主区域颜色不被更改。
- 检查生成结果一致性、SVG ID 唯一性、锚点目标和链接地址，未发现脚本或事件处理器。
- 正文、次要正文、深色区域正文及按钮文字配色的对比度检查均达到 4.5:1。

验证未涉及线上保存配置、真实模型调用、充值或账户操作；实际部署版本仍需在上线阶段复核。

## 线上实施（设计确认后）

1. 核对部署版本的「首页内容」支持 HTML 模式，并确认登录、文档入口及公开能力描述。
2. 将当前首页内容完整复制保存到受控的本地备份文件。
3. 把 `sub2api-home.html` 全部内容粘贴到「首页内容」，保存。
4. 检查未登录、已登录、移动端，以及宿主浅色和深色主题下的显示；确认所有链接和 FAQ 可用。
5. 需要回滚时，将备份内容粘贴回同一配置项并保存。

当前仅交付本地预览，未执行上述线上实施步骤。站点名称、浏览器标题和 favicon 属于宿主独立设置，不由本 HTML 片段变更。
