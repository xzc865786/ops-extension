汇码提供什么服务？

汇码提供 AI API 接入服务，面向希望把模型能力接入应用或工作流的个人开发者与小团队。你可以在控制台管理 API 密钥、查看用量，并按使用手册配置客户端。

可以接入哪些模型与客户端？

请在控制台查看当前开放的模型，并通过使用手册确认客户端所需的接口格式与配置方式。不同模型或客户端的参数可能不同，请按对应说明接入。

如何了解使用费用？

开始调用前，请在控制台核对对应模型的计费与使用规则。调用后，可以查看自己的用量与消费记录。

我的 API 密钥应该放在哪里？

请将密钥保存在你控制的服务端配置或客户端安全配置中，不要放进公开网页、截图或代码仓库。如发现泄露，请及时在控制台处理受影响的密钥。
